# pylia
Python wrapper of LIA

## Usage
1. Install Dependencies
    - Digilent WaveForms SDK
1. Hardware Setup
    - Connect Analog Discovery 2 or 3 to your PC
    - Example wiring:
      - W1 → CH1+
      - GND → CH1−
1. pip install
      ```
      > pip install -U git+https://github.com/daigokk/pylia.git
      ```
